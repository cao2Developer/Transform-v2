# Japan et al

This patch focuses on delivering improvements for non-English keyboards (both hardware and software driven).

## New Features

### Totals are recalculated after visibility events

Previously totals only recalculated when value change events occurred within the table.  They now also occur if a cell changes its visibility state

## Issues Resolved

The following issues are resolved in this release

### Japanese Filtering

Users who are filtering combo-boxes by typing in search, find that options are not shown that match the entered search when they are using a non-english keyboard that swaps characters. This was caused by the browser not firing the right events when the user selected the option they required.   An adjustment has been made based on listening for different events.

### Combo-Width

The width of a combo-box is not accurate in certain grid scenarios especially if the grid is invisible on page load and then made visible later.  This adjustment has been applied to all lists.

### Question focus is missing

Some grid questions had individual question focus missing.  This created specific challenges when trying to complete a grid-based choice question as you could not see the focus when moving between the radio-buttons or checkboxes.

### Error Font-size

Error messages now use 16px not 14px.

### Choice not centred

Choice controls in grids are not centred within their cell

### Click in cell not supported

Choice controls in grids require the user to click on the control directly, the option to click in the cell is not supported.

### Totals in flipped tables

Totals were not being applied correctly when tables are flipped into column orientation

### Totals on double headers

Totals were not being applied correctly when the table had more than one row/column header

### Totals on Error rows

When a table has an error row inserted, totals were being calculated/presented on that row.

### Options visibility does not collapse

choice options subject to visibility rules were not collapsing
