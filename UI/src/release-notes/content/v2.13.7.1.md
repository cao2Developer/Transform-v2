# Combobox Highlight improvements

Following feedback the question.xsl has been updated to remove further examples of error messages appearing as placeholders.  No other files have changed.

This release is focused on further improvements to the combo-box with particular focus on highlighting.  There are a few other improvements that have decided to come along for the ride

## Issues resolved

### No highlight after typing

When typing a filter for the combo-box list the first item is not highlighted.  It is available for selection but its not clear.  Respondent may be tempted to move down and then back up to highlight the first item.

### Multiple highlights are visible

When moving between multiple comboboxes arranged in a grid, it is possible to cause multiple highlights to be displayed, especially if there is a combination of mouse and keyboard use.  This issue has been improved significantly, but occasional double highlights are seen.

### Arrow key action inconsistent

The way the arrow key moves through the list of options differs when a filter is applied.  This can cause the respondent to move the highlight off the list and become invisible.

### Custom Properties are being ignored

Custom properties applied to a combobox are not adjusting the control's configuration

### Errors and information text too small

All errors and information text has been increased to 16px

### Error message removed from placeholder

Error messages are no longer displayed as the placeholder.
