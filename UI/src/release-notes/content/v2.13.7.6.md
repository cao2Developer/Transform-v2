# Exclusive control in grids

This release is focused on issues where responses in a grid would dismiss other responses in the same grid.

## Issues Resolved

### Radio buttons dismiss singleline-number responses

When a combination of a single-number and a radio button appear in the same iteration of a grid, selecting a radio button causes any response in the singleline-number to disappear.

### Similar dismiss issues with other responses

There are issues with various response types that cause the loss of data within a single iteration.  This includes scale and slider questions.

### Exclusive checkboxes not supported when there are two rows of headers

Exclusive checkboxes know they are exclusive because their header is bold.  Once this is detected the bold is removed.  On multi-row headers the bold is on the second row not the first causing it not to be detected.

## Known Issues

### Sliders and special codes in a grid

Sliders and special codes do not dismiss each other correctly when they appear in a single iteration of a grid. The result is two answers to the same question, which then cannot be resolved.  This is not being fixed right now because these are not being used in a survey.  The fix will be provided in the next release.
