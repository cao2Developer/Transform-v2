# 2nd Patch release

## Droplists and Font loading

The calculation of width was being affected by the late loading of fonts.  This release update delays the calculations until after the font has loaded as calculations are affected by font changes.

## Droplists and ResettoNull

This patch is focused on two fixes to the width of droplists and the issues with reset to null for singline questions in grids

## Issues Resolved

### Droplist still wrapping widest item

Certain droplists are still wrapping the widest item

### Singleline questions in grids are not reset

When a grid has a visibility rule then all the questions in the grid may be made invisible.  They should reset to null when this happens.  Singleline and singleline number questions were not resetting.
