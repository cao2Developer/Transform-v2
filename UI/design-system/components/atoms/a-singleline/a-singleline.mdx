## Variations

### Variant

- **Default:** primary input fields in forms.
- **Inline:** compact layouts, tables, inline editing. Class `a-singleline--inline`.

### Answered

- **False:** the field is empty and shows its placeholder.
- **True:** the field shows the answer.

### Text alignment

The text aligns to the start (default), the center or the end. The alignment is set per question. Center and end use the classes `a-singleline--align-center` and `a-singleline--align-end`.

</div>

## States

- **Inactive:** the field is ready to receive input.
- **Active:** the field has keyboard focus and follows the Active State pattern.
- **Error:** the field shows a red border and an error icon. The error appears after the form is submitted with a missing or invalid value.
- **Read only:** the field shows its value, or its placeholder when empty, but users cannot change it. It follows the Read Only State pattern.

Active can be combined with Error, and with Read only when the field receives keyboard focus. Read only is never combined with Error.

</div>

## Skeleton

### Dimensions and spacing

- **Default:** 40px (`--size-xl`) fixed height, 16px (`--space-lg`) horizontal padding and 2px corner radius (`--radius-xs`). The text is vertically centered.
- **Inline:** 32px (`--size-lg`) fixed height and 8px (`--space-sm`) horizontal padding. The text is vertically centered. Only the bottom border is visible and there is no corner radius.

The border is 2px (`--border-width-default`) in the inactive, active and error states and 1px (`--border-width-thin`) in the read only state.

### Error icon

The icon is 16px × 16px (`--size-sm`) and vertically centered. In the default variant, it is 12px (`--space-md`) from the end edge of the field. In the inline variant, it is 8px (`--space-sm`) from the end edge. There are 8px (`--space-sm`) between the text and the icon. The field reserves this space, so the text never overlaps the icon.

### Responsive behavior

The default width is 200px (`--input-width`). It can be changed per question. The text stays on one line and scrolls horizontally when it is longer than the field.

</div>
<div className="docs-section-body">

The component is a single text field. In the error state, the field shows an error icon at its end. The icon is drawn by the field itself, not by a separate component.

Use the native `readonly` attribute, not `disabled`, because a disabled field does not send its value with the form. The field stays in the focus order of the `Tab` key, so users can reach it, review its value and copy it.
