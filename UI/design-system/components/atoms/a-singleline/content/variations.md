The component has two variants, Default and Inline, with no other size or style variations. Each variant has its own page in the sidebar.

### Default

Used in standalone questions and combinations using blocks and loops.

[Open the Default page](?path=/docs/atoms-singleline-default--docs).

### Inline

Vertically compact version for choice questions where an other specify is required. Class `a-singleline--inline`.

[Open the Inline page](?path=/docs/atoms-singleline-inline--docs).
