## Attributes

Attributes are set per question and are the same for both variants.

### Value

The answer. When it is empty, the field shows the placeholder.

### Placeholder

A hint shown while the field is empty.

### Text alignment

Set per question. Start and end follow the reading direction.

- **Start (default):** the text aligns to the start of the field.
- **Center:** the text is centered. Class `a-singleline--align-center`.
- **End:** the text aligns to the end of the field. Class `a-singleline--align-end`.

### Width

In px. 200px by default. It can be changed per question.

### Max length

The most characters the field accepts, with the native `maxlength` attribute. No limit by default. It has no visible effect: the field stops accepting characters at the limit.
