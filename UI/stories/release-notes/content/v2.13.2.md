# Buttons

This is a patch release for 2.13 providing the new buttons functionality.  The updates are encased in the server files and a modified question.xsl.

## New Features

This release introduces buttons

### Buttons within choice

It is now possible to make any option within a choice question a button.  Doing so will automatically make it the equivalent of a radio button as there is no functionality (currently) to denote a button as anything other than exclusive.  The functionality to allow non-exclusive buttons is in place, but there is no mechanism with Dimensions to enable it.

The following is an example of a question that has some options defined as buttons.  The definition of a button is done at an option level simply by changing the style of the control.  this means that any choice question can be used. In this the last option is not defined as a button.

#### Metadata

```metadata
buttonmenulist "" define
    {
        Top "Top Menu"
            style( Control( Type = "Button" ) ),
        Second "Second Option"
             style( Control( Type = "Button" ) ),
        Third "penultimate option"
             style( Control( Type = "Button" ) ),
        Last "the final option"
            style( Control( Type = "Button" ) ),
        Back "Take me back to the main menu"
    };
    
        MenuAsButtons ""
        [ CurrentTab = "Buttons" ]
        style( BgColor = "choice:" )
        templates( Question = "question.htm" )
    categorical [..1]
    {
        use buttonmenulist -
    };
```

### Auto submit on options

A button can be asked to automatically submit the answers to Dimensions.  This is the equivalent of pressing the next button.  A new custom property has been assigned to choice questions.  When the user presses a button it submits the whole page.  This means that this functionality should not be used on a page where there is more than one question.

In the following example the auto-submit functionality has been set alongside a one-size (to keep all the buttons the same size):

```routing
 set customProperties = CreateObject()
 customProperties.submit = true
 set customProperties.onesize = CreateObject()
 customProperties.onesize.state = true
 jsonProperties = JsonSerialize(customProperties)
 MenuAsButtons.Style.Color = jsonProperties
```

## Issues resolved

This release also includes a few bug fixes

### Visibility Categorical grids

Attempts to set the visibility of individual checkboxes were failing because the whole grid was disappearing

### Placeholder used to hold off path open-end responses

Previously the solution used the placeholder functionality to hold a previous answer to an open-end questions that was now off-path.  By mutual consent this feature is being retired.  The functionality still existed when visibility was being used.  This is no longer the case.

### Visibility on Dropdowns was not showing current value

When a page loaded with a dropdown question that had a value but was invisible, the current value was not displayed correctly when then question was made visible.  This only affected dropdowns that were invisible when the page loads and that have a value.
