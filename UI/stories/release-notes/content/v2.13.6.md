# Requested Updates

This is an issue resolution update aimed at providing the base functionality required to launch projects.
Only server files are updated in this release.  There are no changes to the transformation files or the study examples.

## New Features

None

## Issues Resolved

The following known issues have been resolved

### Dropdown: 1st Item cannot receive focus

When using the keyboard a respondent is not able to select the first item in the list by pressing the first character of that item, any searching for a matching item skips the first item.

### Reset on Load

If a question has a value but is loaded onto the page (via visibility rules) in an invisible state, if the state of the question does not change then submitting the page results in the loss of the value set.  A question should only loose its response when the respondent changes a value in another option that causes that question to become invisible.  

### Slider first use cannot select the middle value

The respondent is unable to select the middle value of a slider with an odd number of values.  Clicking on the track does not set the value; using the terminator buttons selects the value immediately above or below.

### Buttons: keyboard can not be used to click a button

When the keyboard is used to click a button the value sets and then resets.  When the button is an auto-submit the form is then submitted without a value; this usually results in a "missing answer" error.

### Choice: Checkbox options can not be toggled using the keyboard

When the keyboard is used to toggle the status of a checkbox the state automatically reverts back to its original status

### Combobox: Pressing down arrow performs two actions

Pressing down arrow on a combo-box (to reveal the list) causes the current selection to change.  It should only reveal the list and not change the current selection.

### Listbox: Moves when scrolling

When a list box appears on a page with other questions and has to be scrolled into view the list box moves relative to its correct position on the page causing it to no longer sit within its question.
