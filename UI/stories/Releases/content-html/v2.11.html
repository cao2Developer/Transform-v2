As the team move back into feature development mode, this release provides the last bug fixes of 2025. There are a couple of features included that deliver parity with v1.96. We have now reached equivalence with that release.

New Features

Question level horizontal scrolling

Previously table-based questions that were wider than the browser window caused the browser window to scroll horizontally. This causes the navigation buttons to disappear. This release implements question-level horizontal scrolling, but only for table based questions. Stand-alone questions are constrained by the width of the browser and apply responsive design when possible.

Reset to Null / Reset to Load

When questions are made invisible, they fall off the response path. If there are values within those questions they need to be reset as the answer is no longer valid. A Page property allows the resesarcher to control whether the reset is to a null value or to the value present when the page was loaded. If a question had no value when the page is loaded this setting is irrelevant (it will reset to null), but if the page loaded with a value Reset to Load will return the hidden question's response to the loaded value.

Reset to Load is achieved by setting the page property to false ```{'resettonull':false}

Off Path to placeholder


In previous releases if an option or response in a question goes off-path (for example a special code is used causing an existing response on the question to no longer be required) this caused the response to be stored in the placeholder.  It has been found that this causes confusion when combined with reset to null and so this feature has been retired.


Keyboard support for scale questions


As part of the Accessibility drive, it is now possible to use the left right arrow keys to increase/decrease the value of the current scale question.  This can be used in combination with the tab key to make the scale question have the focus.  When it has the focus left/right keys adjust the value.


Table Captions for 1 column tables


Dimensions does not publish header captions for tables containing just one question. The table caption custom property can be used to insert one manually.  As an improvement over v1.96, this feature now supports one column tables whether or not they have a row description (if they do they are effectively two-column tables)

{'caption':{'content':'Reasons', 'width': '5em', 'align':'center'}} ```

Issues Resolved

pre/post label formatting on scale questions

When receiving the focus a box appears around the pre/post labels. This box is not supposed to be there.

one-size, sublists

When a choice question has multiple sublists and one-size is applied, each sublist was sized correctly but individually. All sublists should be sized in the same way

Combo-box double selection

There were occasions when two items were appearing as selected in a combo-box. this was identifed as an issue with one option in the list having no text in its description, but it was also partially caused by a bug that resulted in the previous selection not being cleared correctly.
