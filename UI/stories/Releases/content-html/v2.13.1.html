Reset to Null Patch

This is not a full release, it is an update to the v2.13 release to resolve several issues around visibility. The updated files are cascading stylesheets, images and javascript files that are located on the server. There are also changes to the question.xsl file that performs the transformations. There are no changes to the study or templates.

New Features

There are no new features, but there are some changes to the way existing features work

HTML depicting options

In preparation for the arrival of option buttons, changes have been made to the options within choice questions. This to ensure formatting consistency across all types of options (basic options, options with an other specify, options displayed as a button, options displayed as an image). The latter two types are not yet available but are both in development.

Issues Resolves

This patch fixes the following concerns:

Visibility - Boolean Grids

It was not possible to set visibility rules to individual controls within a grid of checkboxes and radio buttons. Any attempt to set rules caused the entire table to become invisible.

Visibility - Filtering

When using filtering to synchronise multiple list or choice questions the filtering applied would only be temporary.

Reset to Null

When items were being made invisible they were not being reset to a null value, this was particularly the case with list based questions that would seem to reset but still show their selection when the list was displayed.

Placeholder for old values

Previously the solution would take a current value and move it to the placeholder (singleline) to preserve that answer either when a question was made invisible or when it was dismissed. There was a decision to abandon this as it created confusion. While it had been removed from other specify options in choice questions it had not been removed elsewhere.

Known Issues

There are still a couple of issues that need to be resolved, they are considered edge cases, but we are working on them as a priority

Dropdowns made visible

If a page loads with a dropdown that has an answer already, but that dropdown is invisible then when it is made visible the dropdown does not look like its answered, when the list is revealed the selected item is visible, so it has been answered. This is a cosmetic issues. Hidden answered questions on page load is very unlikely, we see it in tests but it is unlikely to be used in real-life as there is a danger that the question remains invisible and yet retains its answer.
