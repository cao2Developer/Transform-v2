Combobox

This release resolves a several critical issues around combo-boxes, especially in relation to using both keyboard and mouse for navigation and completion. As combo-boxes, list and dropdown questions share many of the same components, these changes affect those controls as well.

Issues Resolved

Combo-box: Tab key stops working

In a grid when the user removes a value from a combo-box, the tab key stops moving between controls

Combo-box: Highlighted option is not clear

When the down arrow is used to view the list of a current combo-box the highlighted option may not be clearly shown

Combo-box: Inconsistent highlighting when tabbing into the control

When tabbing between combo-box questions in a grid the item shown in the list may not be clearly visible

Combo-box: Multiple lists visible

When moving between combo-box questions in a grid using a combination of keyboard and mouse, multiple lists are visible

Combo-box: List does not always collapse when an option is selected

When the user selects the current option in a combo-box the list does not collapse

Combo-box: horizontal position of list is not correct in certain grids

In certain grids the list appears to the left of the control

Read-only is not always honoured

Across various question types the application of read-only properties does not prevent entry

Choice: All radio-buttons have a transparent centre

When using alt-row shading in grids of choice questions, the radio button image is not consisent with the checkbox image as it has a transparent centre

Grids: Totals are not updating when a cell value changes

When a grid contains totals, the totals are not updating when the cells change, they are only updating when the page loads.

Dynamic Labels: Formatting not consistent

Dynamic labels have a-label-option formatting when they should inherit their format from their parent

Duplicate error messages in Grids

Error messages in grids are duplicated. They appear in the row above and beside the control.
