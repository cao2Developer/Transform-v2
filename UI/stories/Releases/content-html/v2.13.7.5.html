Dropdown width issues

This release provides further improvements around the control of widths of dropdowns

Issues resolved

Dropdown width is not correct for some options causing wrapping in options

There were some issues related to the extra padding we provide dropdowns to ensure that the items are displayed correctly, this padding had not been included in the new calculation.

Special Codes and list questions

While special codes were dismissing the current selection in list questions (list, combo and dropdown) the selection of a new item in the list was not dismissing the special code

Tabstrip missing default property values

In our continued drive to ensure all properties have a default value if not provided, it was found that some tabstrip properties did not have defaults.
