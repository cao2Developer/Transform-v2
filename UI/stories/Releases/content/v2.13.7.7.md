# Multiple Errors on a Page

This release contains fixes to various issues identified by both teams.

## Patch update

Due to an issue with radio button sets in grids, an updated version of question.xsl has been provided.

## Patch update 2

A second patch is being released with updates to two issues:

### exclusive checkboxes in grids

An issue with exclusive checkboxes in a grid was discovered where they were not dismissing other checkboxes and other checkboxes were not dismissing them.

### Incorrect width when defined as a percentage

A minor issue with horizontal questions (sliders/scales) where their width is defined as a percentage of available width has been resolved as well.  These now calculate their width correctly.

## Issues Resolved

The following issues have been resolved

### Only one error is displayed per question

If there are multiple custom errors on a question in a grid then only the first one is displayed

### Multiple errors cause question control to disappear

If there are multiple custom errors on a question in a grid then the control for the question disappears

### droplists are still wrapping

We are still experiencing issues where droplists are not quite the right width.  Another batch of improvements have been implemented, but we are still seeing some inconsistencies

### droplist placeholder truncated in Korean

placeholders are missing one charater as the dropdown is not quite wide enough

### Non-exclusive special codes don't dismiss value

where there is a combination of special codes which are non-exclusive, choosing these options does not dismiss any entered value, nor does entering a value dismiss the special code

### singleline-number does not support , for decimals when language is set to FR

as the input type we use is number only the decimal point can be used to express decimals.  Comma is not supported

### Slider and Special codes

Sliders inside grids are not being dismissed by special codes.
