# Pre-release updates

This release consists of pre-release updates that we have been discussing over the last few weeks.  There are no new features in this release.

This release has been patched to resolve two problems.

## Further Further Issues resolved

### questions inside a grid were not sizing correctly

This was caused by the grid (which had visibility rules applied, not letting the questions within it that its visibility status had changed, consequently they were not prepared properly.  This would create several sizing issues both to the question and the cell in which it is contained.

## Further Issues Resolved

### Combobox : down arrow does not permanently reveal a list

when the down arrow is pressed the list appears and then immediately disappears

### Combobox in Grid: width is restricted

The combobox is working with the width constraints created by the column of the grid.  It needs to push the grid wider so that items can be listed correctly.

### Combobox: width of invisible items

Items which load onto the page in an invisible state do not size correctly

## Issues Resolved

The following issues are resolved in this release

### Grid (Choice/Boolean) - focus 

Choice questions (which are actually boolean questions in grids) were not showing focus when an individual checkbox or radio button has control.  This meant the keyboard user could not tell which control would change state when they pressed the spacebar.

### Dropdown - width

the width of the list does not respect the width of the available area.   if can extend beyond that area to the edge of the page.

### Questions are not showing focus

There should be a focus for the current control and the current question, current question focus is not appearing

### Combobox - filter not working for Japanese keyboards

Due to the way Japanese entry works filtering was not working correctly 

### Tab Order - full pages tab to the submit button

On Chromium-based browsers a completed page of controls would tab to the submit button at the bottom of the page rather than tab to the first control on the screen.

### Lists are sometimes covered by other objects

The list from a dropdown or combobox, when visible, can be partially covered by other elements on the page, for example a slider.

## Known Issues

These are issues that have been raised that are not yet resolved

### Jump to Error

Officially this has not yet been resolved, nor recreated.  But changes to the tab order may have resolved it accidently.  Could you confirm

### Special codes don't trigger visibility rules on first character entry

In a input/special code combination where the special code is used to drive visibility rules. the visibility rule may not run correctly when the user makes an single character entry into the input

### One-size calculation does not account for hidden options

Options that are hidden in a choice question are not used to calculate the max width/height of options.  When they are made visible they may overlap with other items.
